Featured · Independent project

SENTINEL V3 — Fraud authorization engine

A deterministic fraud-decision engine for West African financial institutions, built on one principle: the point that executes a transaction should not be the point that authorizes it. The settlement point can verify a signed decision, but never produce one.

  • Ed25519-signed authorizations with challenge-response anti-replay
  • Hostile-operator threat model: missing information hardens the decision, never relaxes it
  • Blind inter-institution lookup (OPRF / DH-PSI) with adaptive anti-enumeration quotas
  • Bounded-memory stream detectors and a hash-chained append-only journal
  • 161 passing assertions; reproducible benchmark on a synthetic population
  • Benchmark-driven fix cut false refusals from 38.44 % to 0.22 % while still catching 5/5 fraud families
